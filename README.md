# rdr2-mods

A personal collection of mods for Red Dead Redemption 2.

> **About this repo:** a personal hobby project for single-player Red Dead Redemption 2. The C++ plugins were written with an AI coding assistant (Claude Code), with me directing the work and testing it in game. It isn't a sample of my own C++ experience.

Each mod here is one of two things:

- a mod I created from scratch, or
- an existing mod by another developer that I changed or fixed.
